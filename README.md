# Archivo → Markdown

Sube un **PDF, Word (.docx) o PowerPoint (.pptx)** y conviértelo a Markdown. Conversión 100% local y gratis con [MarkItDown](https://github.com/microsoft/markitdown.git). No necesitas API ni clave.

https://archivo-a-markdown.streamlit.app/

## Uso

```bash
pip install -r requirements.txt
streamlit run app.py
```

Abre http://localhost:8501

## Formatos

Principales: `pdf`, `docx`, `pptx`. También: `xlsx`, `csv`, `txt`, `md`, `html`, imágenes.
